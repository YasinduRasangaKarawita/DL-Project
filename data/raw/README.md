# Raw dataset

Place the downloaded, unaugmented source dataset here for local runs. Image files are ignored by Git.

The current local class folders contain synthetic smoke-test images generated by `src/data/download_data.py`; they are not the assignment dataset and must be replaced before final experiments.

Expected image-folder layout for the current loader:

```text
data/raw/
├── Apple___Apple_scab/
├── Apple___healthy/
└── ...
```

Record the real dataset source, version, license, download date, checksum, sample count, and any exclusions in `data/README.md`.
