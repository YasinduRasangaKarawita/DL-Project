# Raw dataset

The reproducible acquisition command places the downloaded, unaugmented source dataset
here for local runs. Image files are ignored by Git.

The current local class folders contain synthetic smoke-test images generated by `src/data/download_data.py`; they are not the assignment dataset and must be replaced before final experiments.

Real-dataset layout:

```text
data/raw/plantvillage/
├── color/
│   ├── Apple___Apple_scab/
│   ├── Apple___healthy/
│   └── ...
└── metadata/
```

Acquire it from the repository root with:

```powershell
python scripts/prepare_data.py download
```

The legacy class folders directly under `data/raw/` are synthetic smoke-test data. The
real dataset source, immutable revision, license declaration, checksums, expected sample
counts, and exclusions are documented in `data/README.md` and
`data/plantvillage_source.lock.json`.
